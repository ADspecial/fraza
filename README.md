# fraza

Simple password generator using passphrase in Russian

### Правила формирования пароля:

- пароль создается на основе **парольной фразы**
- беруться первые несколько букв из каждого слова в парольной фразе
- пароль набирается в ангийской раскладке клавиатуры

### Правила генерации парольной фразы:

[(attribute)+ subject + (adverbial) + predicate + object]

- подлежащие (subject)
- дополнения (object)
- сказуемые (predicate)
- определения (attribute)
- обстоятельство (adverbial)

Для работы используется словарь в JSON формате, который имеет следующую структуру:

```
{
  "subject": ["кот", "мама", "студент"],
  "object": ["друга", "книгу"],
  "predicate": ["пишет", "идёт"],
  "attribute": ["красивый", "старый"],
  "adverbial": ["быстро", "весело"]
}
```

### Аргументы

- d (--difficulty), сложность пароля по **уровням** (simple, standart, complex).
- f (--file), путь до файла с паролями на выходе
- w (--word), количество слов в фразе (max = 5)
- l (--letter), количество букв из каждого слова (max = 4)
- n (--number), добавить число в начало пароля (100-999)
- c (--capitalized), использовать заглавные буквы в начале слов
- wc (--wildcard), использовать спецсимвол в пароле, разграничители между словами в парольной фразе по очереди (!, @, #, $, %, ^, &, \*)

Default вызов генерация одного станартного пароля

Генерация паролей трех уровней:

- простой (simple): 4 слова в фразе, 3 буквы из каждого слова
- станадртный (standart): 4 слова в фразе, 3 буквы из каждого слова, число в начале пароля, заглавные буквы в начале слов
- сложный (complex): 5 слова в фразе, 4 буквы из каждого слова, число в начале пароля, заглавные буквы в начале слов, спецсимволы в качестве разделителей
